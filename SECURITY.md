# Security Policy

## Supported Versions

The following versions of TechHelp Support Bot are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| Latest main branch | ✅ Yes |
| Older releases | ❌ Not guaranteed |

## Reporting a Vulnerability

We take security seriously. If you discover a security issue, please do not open a public issue or discuss it in a public discussion thread.

Instead, report it privately in one of the following ways:

- Open a private security advisory in GitHub (preferred if enabled for the repository)
- Contact the maintainers through GitHub privately
- Use the repository's private security reporting mechanism if available

Please include the following in your report:

- Description of the vulnerability
- Steps to reproduce the issue
- Impact assessment
- Any relevant logs, screenshots, or proof of concept
- Affected version or commit hash

## Response Expectations

We aim to acknowledge valid reports within 5 business days and work toward a fix as quickly as possible. We may ask for additional information during the investigation.

## Responsible Disclosure

We ask that you:

- Give maintainers time to investigate and fix the issue before public disclosure
- Avoid leaking or exploiting the vulnerability beyond what is necessary to verify it
- Do not access or modify data beyond what is required for responsible testing

## Sensitive Information

Please never share or expose:

- Bot tokens
- API keys
- Webhook secrets
- OAuth credentials
- Database credentials
- Private environment variables

If you are contributing to the project, keep all secrets in local environment files and never commit them to the repository.

## Public Issues

Security issues are not handled via public GitHub issues. Please keep vulnerability reports private until a fix has been published.
