## 🇩🇪 Deutsch

Du möchtest Teil des **TechHelp-Teams** werden? Super! 💙 Hier erfährst du, welche Rollen es gibt und wie die Bewerbung abläuft.

### 🎯 Rollen

| Rolle | Aufgaben |
| --- | --- |
| 🛡️ **Moderation** | Community betreuen, Regeln durchsetzen, bei Konflikten vermitteln |
| 🛟 **Support / Helfer** | Nutzern bei Fragen und Einrichtung helfen |
| 💻 **Entwicklung** | Am Bot und an Tools mitentwickeln |
| 🎨 **Design / UI** | Grafiken, UI-Ideen und Gestaltung |
| 📚 **Dokumentation** | Anleitungen und Doku pflegen und verbessern |
| 💬 **Community-Management** | Discussions, Events und Community-Aktionen |

### ✅ Was wir uns wünschen

- Respektvoller Umgang (siehe [Verhaltenskodex](../CODE_OF_CONDUCT.md))
- Zuverlässigkeit und etwas regelmäßige Zeit
- Freude an Teamarbeit
- Für Entwicklung/Design: relevante Grundkenntnisse

Es gibt **keine** Pflicht zu einem Mindestalter oder „perfekten" Skills – Motivation zählt.

### 📝 So bewirbst du dich

1. Öffne ein Issue mit dem Template **🧑‍💼 Team-Bewerbung**.
2. Fülle die Felder ehrlich aus.
3. Das Team meldet sich bei dir (ggf. über Discord).

👉 [Jetzt bewerben](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new?template=team-bewerbung.yml)

### 🔄 Ablauf

```text
📨 Bewerbung → 👀 Sichtung → 💬 Gespräch → ✅ Zusage / ❌ Absage
```

Eine Bewerbung ist keine Garantie für eine Aufnahme. Auch bei einer Absage bist du in der Community weiterhin herzlich willkommen. 💙

## 🇬🇧 English

Want to become part of the **TechHelp team**? Awesome! 💙 Here's what roles exist and how applying works.

### 🎯 Roles

| Role | Responsibilities |
| --- | --- |
| 🛡️ **Moderation** | Look after the community, enforce rules, mediate conflicts |
| 🛟 **Support / Helper** | Help users with questions and setup |
| 💻 **Development** | Help develop the bot and tools |
| 🎨 **Design / UI** | Graphics, UI ideas, and visual design |
| 📚 **Documentation** | Maintain and improve guides and docs |
| 💬 **Community management** | Discussions, events, and community activities |

### ✅ What we look for

- Respectful conduct (see [Code of Conduct](../CODE_OF_CONDUCT.md))
- Reliability and some regular time
- Enjoying teamwork
- For development/design: relevant basic skills

There is **no** minimum age requirement or need for "perfect" skills – motivation matters.

### 📝 How to apply

1. Open an issue using the **🧑‍💼 Team application** template.
2. Fill in the fields honestly.
3. The team will get back to you (possibly via Discord).

👉 [Apply now](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new?template=team-bewerbung.yml)

### 🔄 Process

```text
📨 Application → 👀 Review → 💬 Interview → ✅ Accepted / ❌ Declined
```

An application is not a guarantee of acceptance. Even if declined, you remain very welcome in the community. 💙
