# 🌱 Onboarding für Einsteiger / Onboarding for Newcomers

**🇩🇪 [Deutsch](#-deutsch) · 🇬🇧 [English](#-english)**

## 🇩🇪 Deutsch

Neu hier? Willkommen! 💙 Dieser Guide hilft dir, in wenigen Minuten loszulegen.

### 1. 👀 Verschaff dir einen Überblick

- Lies die [README](../README.md) für das große Ganze.
- Wirf einen Blick in die [Community-Prinzipien](../COMMUNITY.md) und den [Verhaltenskodex](../CODE_OF_CONDUCT.md).

### 2. 🌱 Finde einen einfachen Einstieg

Suche in den Issues nach diesen Labels:

- `good first issue` – ideal für den allerersten Beitrag
- `help wanted` – hier freuen wir uns besonders über Unterstützung
- `documentation` – Doku-Verbesserungen sind ein super Einstieg

👉 [Good first issues ansehen](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)

### 3. 💬 Sag Hallo

Stell dich in den [Discussions](https://github.com/Techhelp-Support/Techhelp-Support-Bot/discussions) vor. Fragen sind ausdrücklich erwünscht – niemand wird für eine Frage schief angeschaut.

### 4. 🚀 Ersten Beitrag leisten

- 💡 Idee? → Issue mit **💡 Neue Idee**
- 🐛 Fehler? → Issue mit **🐛 Fehler melden**
- 💻 Code? → Fork, Branch, Pull Request (siehe [CONTRIBUTING.md](../CONTRIBUTING.md))

### 5. 🙌 Anerkennung

Jeder Beitrag zählt und wird über [All Contributors](../CONTRIBUTORS.md) sichtbar gemacht – auch nicht-technische.

## 🇬🇧 English

New here? Welcome! 💙 This guide helps you get started in just a few minutes.

### 1. 👀 Get an overview

- Read the [README](../README.md) for the big picture.
- Take a look at the [community principles](../COMMUNITY.md) and the [Code of Conduct](../CODE_OF_CONDUCT.md).

### 2. 🌱 Find an easy entry point

Search the issues for these labels:

- `good first issue` – perfect for a first contribution
- `help wanted` – we'd especially love help here
- `documentation` – doc improvements are a great start

👉 [Browse good first issues](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)

### 3. 💬 Say hi

Introduce yourself in [Discussions](https://github.com/Techhelp-Support/Techhelp-Support-Bot/discussions). Questions are explicitly welcome – no one is judged for asking.

### 4. 🚀 Make your first contribution

- 💡 Idea? → issue using **💡 New idea**
- 🐛 Bug? → issue using **🐛 Bug report**
- 💻 Code? → fork, branch, pull request (see [CONTRIBUTING.md](../CONTRIBUTING.md))

### 5. 🙌 Recognition

Every contribution counts and is made visible via [All Contributors](../CONTRIBUTORS.md) – including non-technical ones.
