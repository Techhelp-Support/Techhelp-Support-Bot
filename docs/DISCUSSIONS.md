# 💬 GitHub Discussions – Community-Guide

**🇩🇪 [Deutsch](#-deutsch) · 🇬🇧 [English](#-english)**

---

## 🇩🇪 Deutsch

**Discussions** sind der Ort für alles, was (noch) kein Issue ist: Fragen, Ideen im frühen Stadium, Feedback und der Austausch mit anderen aus der Community. 💙

### 🗂️ Empfohlene Kategorien

| Kategorie | Format | Zweck |
| --- | --- | --- |
| 📣 **Ankündigungen** | Announcement | News und Updates vom TechHelp-Team |
| 💡 **Ideen** | Open-ended | Ideen sammeln, bevor sie zum Issue werden |
| 🙋 **Fragen & Hilfe** | Q&A | Fragen stellen und beantworten lassen |
| 🗳️ **Umfragen** | Poll | Community-Abstimmungen zu Features |
| 🎉 **Showcase** | Open-ended | Zeig, was du gebaut hast |
| 💬 **Allgemein** | Open-ended | Alles andere rund um den Bot |

### 🤔 Discussion oder Issue?

| Nutze eine **Discussion**, wenn ... | Nutze ein **Issue**, wenn ... |
| --- | --- |
| du eine Frage hast | du einen konkreten Fehler melden willst |
| du eine Idee erst diskutieren möchtest | du eine ausgearbeitete Idee einreichst |
| du Feedback einholen willst | du eine konkrete Verbesserung vorschlägst |
| du etwas Gebautes zeigen möchtest | etwas nachweislich nicht funktioniert |

Aus einer guten Discussion kann jederzeit ein Issue werden. 👍

### ⚙️ Discussions aktivieren (für Maintainer)

Discussions müssen einmalig im Browser aktiviert werden – das geht nicht per Datei:

1. Repo öffnen → **Settings**
2. Abschnitt **Features** → Häkchen bei **Discussions**
3. Im Reiter **Discussions** die Kategorien aus der Tabelle anlegen
4. Optional: den [Willkommens-Post](./discussions/WELCOME.md) posten und anpinnen

Sobald Discussions aktiv sind, werden die Templates aus `.github/DISCUSSION_TEMPLATE/` automatisch angeboten und neue Beiträge per Workflow begrüßt.

### ✨ Tipps für gute Beiträge

- 🔎 Schau kurz, ob es das Thema schon gibt.
- 🏷️ Wähle die passende Kategorie.
- 📝 Formuliere einen klaren Titel.
- 🤝 Bleib freundlich und sachlich – siehe [Verhaltenskodex](../CODE_OF_CONDUCT.md).
- 👍 Markiere in Q&A die hilfreichste Antwort als Lösung.

👉 https://github.com/Techhelp-Support/Techhelp-Support-Bot/discussions

## 🇬🇧 English

**Discussions** are the place for anything that isn't (yet) an issue: questions, early-stage ideas, feedback, and chatting with the community. 💙

### 🗂️ Recommended categories

| Category | Format | Purpose |
| --- | --- | --- |
| 📣 **Announcements** | Announcement | News and updates from the TechHelp team |
| 💡 **Ideas** | Open-ended | Collect ideas before they become issues |
| 🙋 **Q&A** | Q&A | Ask and answer questions |
| 🗳️ **Polls** | Poll | Community votes on features |
| 🎉 **Showcase** | Open-ended | Show what you've built |
| 💬 **General** | Open-ended | Everything else about the bot |

### 🤔 Discussion or issue?

| Use a **discussion** when ... | Use an **issue** when ... |
| --- | --- |
| you have a question | you want to report a concrete bug |
| you want to discuss an idea first | you're submitting a fleshed-out idea |
| you want to gather feedback | you're proposing a concrete improvement |
| you want to show something you built | something demonstrably doesn't work |

A good discussion can turn into an issue anytime. 👍

### ⚙️ Enabling Discussions (for maintainers)

Discussions must be enabled once in the browser – this can't be done via a file:

1. Open the repo → **Settings**
2. **Features** section → check **Discussions**
3. In the **Discussions** tab, create the categories from the table
4. Optional: post and pin the [welcome post](./discussions/WELCOME.md)

Once enabled, the templates in `.github/DISCUSSION_TEMPLATE/` are offered automatically and new posts are welcomed by a workflow.

### ✨ Tips for good posts

- 🔎 Check whether the topic already exists.
- 🏷️ Pick the right category.
- 📝 Write a clear title.
- 🤝 Stay friendly and constructive – see [Code of Conduct](../CODE_OF_CONDUCT.md).
- 👍 In Q&A, mark the most helpful answer as the solution.

👉 https://github.com/Techhelp-Support/Techhelp-Support-Bot/discussions
