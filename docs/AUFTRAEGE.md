## 🇩🇪 Deutsch

Du brauchst Hilfe bei einem Projekt? Hier kannst du einen Auftrag anfragen – egal ob Website, Bot, Tool oder etwas anderes. 🚀

### 🧩 Was du anfragen kannst

| Bereich | Beispiele |
| --- | --- |
| 🌐 **Websites** | Landingpages, Portfolios, kleine Web-Apps |
| 🤖 **Bots** | Discord-Bots, Automatisierungen, Integrationen |
| 📊 **Dashboards / Web-Apps** | Admin-Panels, Tools mit Login |
| ⚙️ **Automatisierung** | Workflows, Skripte, Anbindungen |
| 🎨 **Design / Grafik** | Logos, Banner, UI-Entwürfe |
| 💡 **Beratung** | Technische Fragen, Konzepte, Reviews |

Auch andere Ideen sind willkommen – frag einfach an.

### 📝 So fragst du an

1. Öffne ein Issue mit dem Template **📋 Auftrag anfragen**.
2. Beschreibe dein Vorhaben möglichst genau (Funktionen, Budget, Zeitrahmen).
3. Das Team meldet sich mit einer Einschätzung – meist über Discord.

👉 [Auftrag anfragen](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new?template=auftrag.yml)

### 🔄 Ablauf

```text
📨 Anfrage → 👀 Sichtung → 💬 Absprache & Angebot → 🛠️ Umsetzung → ✅ Übergabe
```

### ⚠️ Bitte beachten

- Eine Anfrage ist **keine** verbindliche Zusage – Machbarkeit und Aufwand werden erst geprüft.
- Preise und Bedingungen werden individuell besprochen.
- Bitte **keine** Zugangsdaten, Tokens oder Passwörter ins Issue schreiben.
- Es gilt der [Verhaltenskodex](../CODE_OF_CONDUCT.md).

## 🇬🇧 English

Need help with a project? You can request a commission here – whether a website, a bot, a tool, or something else. 🚀

### 🧩 What you can request

| Area | Examples |
| --- | --- |
| 🌐 **Websites** | Landing pages, portfolios, small web apps |
| 🤖 **Bots** | Discord bots, automations, integrations |
| 📊 **Dashboards / web apps** | Admin panels, tools with login |
| ⚙️ **Automation** | Workflows, scripts, integrations |
| 🎨 **Design / graphics** | Logos, banners, UI drafts |
| 💡 **Consulting** | Technical questions, concepts, reviews |

Other ideas are welcome too – just ask.

### 📝 How to request

1. Open an issue using the **📋 Request a commission** template.
2. Describe your idea as clearly as possible (features, budget, timeframe).
3. The team will get back to you with an estimate – usually via Discord.

👉 [Request a commission](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new?template=auftrag.yml)

### 🔄 Process

```text
📨 Request → 👀 Review → 💬 Discussion & quote → 🛠️ Build → ✅ Handover
```

### ⚠️ Please note

- A request is **not** a binding commitment – feasibility and effort are reviewed first.
- Prices and terms are discussed individually.
- Please do **not** put credentials, tokens, or passwords into the issue.
- The [Code of Conduct](../CODE_OF_CONDUCT.md) applies.
