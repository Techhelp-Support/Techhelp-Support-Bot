## 🇩🇪 Deutsch

Willkommen im **TechHelp Support Bot Community-Repository**! 🚀

Der zentrale Ort für **Ideen, Verbesserungen, Fehlerberichte und den Austausch** rund um den [TechHelp Support Bot](https://bot.techhelp-support.de/).

### 🧭 Schnellzugriff

| Ich möchte ... | Los geht's |
| --- | --- |
| 💡 eine Idee einreichen | [Neues Issue → 💡 Neue Idee](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new/choose) |
| 🛠️ eine Verbesserung vorschlagen | [Neues Issue → 🛠️ Verbesserung](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new/choose) |
| 🐛 einen Fehler melden | [Neues Issue → 🐛 Fehler melden](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new/choose) |
| 💬 diskutieren / Fragen stellen | [GitHub Discussions](https://github.com/Techhelp-Support/Techhelp-Support-Bot/discussions) |
| 🤝 mitwirken | [CONTRIBUTING.md](./CONTRIBUTING.md) |
| 🛟 Support brauchen | [SUPPORT.md](./SUPPORT.md) |
| 🔐 eine Sicherheitslücke melden | [SECURITY.md](./SECURITY.md) |

Unser Ziel ist es, den TechHelp Support Bot gemeinsam weiterzuentwickeln und immer besser auf die Bedürfnisse unserer Nutzer anzupassen.

### 🧠 Welche Ideen kannst du einreichen?

Grundsätzlich kannst du alles vorschlagen, was den TechHelp Support Bot sinnvoll erweitern oder verbessern könnte. Zum Beispiel:

* 🎫 Neue Ticket-Funktionen
* 🛠️ Neue Moderationsfunktionen
* 🔐 Verbesserungen am Verifizierungs-System
* 📊 Neue Dashboard-Funktionen
* 🤖 Neue Bot-Funktionen
* 🔔 Neue Benachrichtigungen
* 🌐 Verbesserungen an der Weboberfläche
* ⚡ Performance-Verbesserungen
* 🎨 UI-/Design-Ideen
* 🔗 Neue Integrationen
* 💡 Komplett neue Funktionen

Auch kleinere Ideen sind willkommen!

### 📥 Eine Idee einreichen

Wenn du eine Idee hast, kannst du dafür ein **GitHub Issue** erstellen. Bitte beschreibe deine Idee möglichst verständlich.

**Beispiel-Titel:**

> Ticket automatisch schließen, wenn 24 Stunden keine Aktivität stattgefunden hat

**Beschreibung:**

> Es wäre praktisch, wenn Tickets nach einer bestimmten Zeit automatisch geschlossen werden könnten. Die Zeit sollte im Dashboard konfigurierbar sein (z. B. 12 / 24 / 48 Stunden oder deaktiviert).

Je genauer die Idee beschrieben ist, desto einfacher können wir sie verstehen und bewerten.

### 🔎 Was passiert mit meiner Idee?

Nachdem eine Idee eingereicht wurde, wird sie vom **TechHelp-Team** geprüft. Dabei können wir die Idee besprechen, Rückfragen stellen, sie mit anderen Vorschlägen zusammenführen, für eine zukünftige Version vormerken, in die Entwicklung aufnehmen oder erklären, warum sie aktuell nicht umgesetzt werden kann.

**Eine eingereichte Idee ist keine Garantie dafür, dass sie umgesetzt wird.**

| ----------------- | -------------------------------------- |

### 🚫 Bitte beachten

Bitte reiche keine Inhalte ein, die gegen die GitHub-Regeln verstoßen, andere Personen angreifen, sensible Zugangsdaten (Tokens, Passwörter, API-Keys) enthalten, absichtlich Sicherheitslücken ausnutzen oder nichts mit dem TechHelp Support Bot zu tun haben.

**🔐 Sicherheitslücken bitte niemals als normales Issue veröffentlichen** – siehe [SECURITY.md](./SECURITY.md).

## 🇬🇧 English

Welcome to the **TechHelp Support Bot community repository**! 🚀

This is the central place for **ideas, improvements, bug reports, and discussion** around the [TechHelp Support Bot](https://bot.techhelp-support.de/).

### 🧭 Quick links

| I want to ... | Go |
| --- | --- |
| 💡 submit an idea | [New issue → 💡 New idea](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new/choose) |
| 🛠️ suggest an improvement | [New issue → 🛠️ Improvement](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new/choose) |
| 🐛 report a bug | [New issue → 🐛 Bug report](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new/choose) |
| 💬 discuss / ask questions | [GitHub Discussions](https://github.com/Techhelp-Support/Techhelp-Support-Bot/discussions) |
| 🤝 contribute | [CONTRIBUTING.md](./CONTRIBUTING.md) |
| 🛟 get support | [SUPPORT.md](./SUPPORT.md) |
| 🔐 report a security issue | [SECURITY.md](./SECURITY.md) |

Our goal is to evolve the TechHelp Support Bot together with its community and keep improving it to fit our users' needs.

### 🧠 What ideas can you submit?

Anything that could meaningfully extend or improve the TechHelp Support Bot. For example:

* 🎫 New ticket features
* 🛠️ New moderation features
* 🔐 Verification system improvements
* 📊 New dashboard features
* 🤖 New bot features
* 🔔 New notifications
* 🌐 Web interface improvements
* ⚡ Performance improvements
* 🎨 UI / design ideas
* 🔗 New integrations
* 💡 Completely new features

Small ideas are welcome too!

### 📥 Submitting an idea

If you have an idea, open a **GitHub issue** and describe it as clearly as possible.

**Example title:**

> Automatically close a ticket after 24 hours of inactivity

**Description:**

> It would be handy if tickets could close automatically after a certain time. The duration should be configurable in the dashboard (e.g. 12 / 24 / 48 hours or disabled).

The more detail you provide, the easier it is for us to understand and evaluate the idea.

### 🔎 What happens to my idea?

Once submitted, the **TechHelp team** reviews it. We may discuss it, ask questions, merge it with other suggestions, mark it for a future version, take it into development, or explain why it cannot be implemented right now.

**Submitting an idea is not a guarantee that it will be implemented.**

### 🏷️ Idea statuses

| Status            | Meaning                          |
| ----------------- | -------------------------------- |
| 💡 `idea`         | New idea                         |
| 🔍 `review`       | Being reviewed by the team       |
| 💬 `discussion`   | Needs further discussion         |
| 📋 `planned`      | Planned for a future version     |
| 🛠️ `in-progress` | Development in progress          |
| ✅ `implemented`   | Already implemented              |
| ❌ `declined`      | Not being implemented right now  |
| 🔁 `duplicate`    | Already existing idea            |

### 🚫 Please note

Please do not submit content that violates GitHub's rules, attacks other people, contains sensitive credentials (tokens, passwords, API keys), intentionally exploits vulnerabilities, or is unrelated to the TechHelp Support Bot.

**🔐 Never disclose security vulnerabilities as a regular issue** – see [SECURITY.md](./SECURITY.md).
