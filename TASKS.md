### 📌 Wichtig bei den Checkboxen

Wenn du diese Datei als **`TASKS.md`** in dein Repository hochlädst, kannst du die Kästchen auf GitHub direkt anklicken. GitHub speichert den Status dann als `- [x]` bzw. `- [ ]`.

Und bei den Aufgaben mit `📍` weißt du direkt, **wo du die jeweilige Einstellung oder Datei findest**.

Für die Lizenz würde ich also zunächst:

```text
LICENSE
└── MIT License
````

nehmen. Die eigentliche Lizenz sollte über GitHub's Lizenzvorlage hinzugefügt werden, statt eine aus dem Internet kopierte Version mit möglicherweise falschen Angaben zu verwenden.
