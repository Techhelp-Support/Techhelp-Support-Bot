## 🇩🇪 Deutsch

### 🤝 So kannst du eigene Ideen eintragen

Diese Liste ist für **kleinere Änderungen und spontane Ideen** gedacht, die kein eigenes großes Projekt brauchen. Jeder darf mitmachen:

1. 🍴 **Forke** dieses Repository (Button „Fork" oben rechts auf GitHub).
2. ✍️ Trage deine Idee in deinem Fork unter **💡 Ideen** ein – schreib sie einfach als neuen Punkt dazu.
3. 🔀 Erstelle einen **Pull Request** zurück zu diesem Repo.
4. 👀 Das Team schaut sich deinen Vorschlag an.

> 💡 Kein Git-Profi? Du kannst die Datei auch direkt auf GitHub bearbeiten (Bleistift-Symbol ✏️) – GitHub legt den Fork und den Pull Request dann automatisch für dich an. Eine Schritt-für-Schritt-Anleitung findest du in [docs/FORK.md](./docs/FORK.md).

Alternativ kannst du deine Idee auch einfach als [Issue](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new?template=neue-idee.yml) einreichen. 🙂

## 🇬🇧 English

### 🤝 How to add your own ideas

This list is for **small changes and spontaneous ideas** that don't need a big project of their own. Everyone is welcome to join in:

1. 🍴 **Fork** this repository (the "Fork" button at the top right on GitHub).
2. ✍️ Add your idea to your fork under **💡 Ideas** – just add it as a new bullet point.
3. 🔀 Open a **pull request** back to this repo.
4. 👀 The team will review your suggestion.

> 💡 Not a Git pro? You can also edit the file directly on GitHub (the pencil icon ✏️) – GitHub then creates the fork and pull request for you automatically. A step-by-step guide is in [docs/FORK.md](./docs/FORK.md).

Alternatively, you can simply submit your idea as an [issue](https://github.com/Techhelp-Support/Techhelp-Support-Bot/issues/new?template=neue-idee.yml). 🙂
