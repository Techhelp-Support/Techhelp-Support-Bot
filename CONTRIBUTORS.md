# 🙌 Mitwirkende / Contributors

**🇩🇪 [Deutsch](#-deutsch) · 🇬🇧 [English](#-english)**

---

## 🇩🇪 Deutsch

Dieses Projekt lebt von seiner Community. Wir danken allen, die Ideen einbringen, Fehler melden, Code beitragen, bei der Doku helfen oder andere unterstützen. 💙

Wir nutzen die [All Contributors](https://allcontributors.org/)-Spezifikation, um Beiträge **jeder Art** anzuerkennen – nicht nur Code, sondern auch Ideen 🤔, Fehlerberichte 🐛, Dokumentation 📖, Design 🎨, Tests 🧪 und Community-Hilfe 💬.

### So wird jemand hinzugefügt

Ein Maintainer kommentiert in einem Issue oder PR:

```text
@all-contributors please add @username for ideas, bug, doc
```

Der All-Contributors-Bot ergänzt die Person dann automatisch in der Liste unten.

---

## 🇬🇧 English

This project thrives on its community. We thank everyone who brings ideas, reports bugs, contributes code, helps with docs, or supports others. 💙

We use the [All Contributors](https://allcontributors.org/) specification to recognize contributions of **every kind** – not just code, but also ideas 🤔, bug reports 🐛, documentation 📖, design 🎨, testing 🧪, and community help 💬.

### How someone gets added

A maintainer comments on an issue or PR:

```text
@all-contributors please add @username for ideas, bug, doc
```

The All Contributors bot then adds the person to the list below automatically.
